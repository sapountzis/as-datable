# A technical portfolio that teaches through its methods

The site presents Andreas Sapountzis’s work through technical fields and methods. Its audience is technically curious readers and AI/ML/DS/SWE professionals who do not know the original application domains. The homepage is an Experience surface with substantial Read content; topic pages are Read surfaces.

Every element must identify expertise, teach a substantive idea, explain a consequential distinction or support navigation. Remove filler panels, repeated summaries, generic conclusions and controls without meaningful effects. No company narratives, case studies, promotional headings, rhetorical questions or unsupported achievements.

## Reading structure

Identity and portrait → Areas of expertise → Selected methods → Background → Contact. The expertise index precedes the animations, uses four formal fields and places each of the twelve canonical topics once. The selected methods are supervised rule discovery, recommendation/probability, agents/tools and statistical signatures/community detection, in that order. Topic.title is authoritative everywhere.

Introductions establish the technical area and why its output is useful. A separate example introduction defines synthetic observations, attributes, targets and references before a figure. Technical pages expand the mathematics, assumptions and interpretation. Scientific analysis remains text-led; no invented PCA demonstration.

## Visual identity

Keep self-hosted Instrument Sans, the supplied portrait and blue/teal light/dark palettes in globals.css. The shared page width is 1,160px with readable prose around 68 characters. Use typography and spacing for hierarchy, thin dividers between methods and a two-column expertise index that becomes one column on narrow screens. No generic card grid or decorative technical graphics.

Native HTML carries prose, calculations, tables, legends and controls. SVG carries geometric relationships and transformations. Scene coordinates use the player's measured content width, so SVG units remain CSS pixels and diagram labels remain at least 14px. Scenes use the full available width on topic pages and reflow their content rather than shrinking a fixed 960px viewBox.

## Playback

One persistent frame, with observations and identities retained through transformations. Start at a defined input state, paused. Progressive results and narration use the same timeline. Parameter changes and inspection pause without seeking; only Replay resets. Starting a second player transfers ownership. Pause offscreen and on hidden tabs. No autoplay or loops. Reduced motion provides manual progression; JavaScript-disabled pages expose an ordered textual explanation.

Use the installed Next.js, React, TypeScript, Motion, HTML and SVG stack. Numerical fixtures are generated offline with locked Python dependencies. No live models, numerical runtime dependencies or new animation engine. Preserve direct SVG geometry subscriptions to avoid stale coordinates during responsive reflow. Graph resolution changes animate; viewport resizing updates target coordinates immediately so nodes cannot travel outside a newly narrowed canvas.

## Agent scene direction

Actors stay stationary. A coordinator above three aligned worker columns delegates bounded checks; the conditional third worker is created only after incompatible population evidence returns. Each worker owns a short local action/tool/observation loop, retained evidence and next decision. Requests leave an agent's right boundary, observations return to its bottom boundary, and findings follow the delegation route back to the coordinator. Desktop shows the three aligned columns; mobile shows a worker-status row and one focused loop in the same position.

Draw the base orchestration tree once, including the stem from the coordinator boundary. Active signals overlay that base after it is painted. Dispatch intervals are staggered to avoid multiple overlays on a shared trunk. Agent presence fades in without relocating actors. Completed loops become subordinate; all active signals end before synthesis. Typed operations, computed observations and authored decisions remain distinct. Source inspection is an anchored overlay and does not resize the figure.

All changing prose uses intrinsic stacked text alternatives to reserve exactly the maximum required text space at the current width. This includes narration, calculations, input strings and outputs. Playback, scrubbing, case changes and inspection preserve widget size; explicit Technical notes disclosure remains normal document flow. Avoid reserving a large empty canvas for late results. Derive the current narration from progress and the current trace, so switching traces cannot retain an invalid chapter index.
